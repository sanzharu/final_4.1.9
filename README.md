# Literary Haven — Платформа для чтения и публикации книг

Literary Haven — веб-приложение для чтения и публикации художественной литературы, вдохновлённое платформами FicBook и AO3.

## Стек технологий

- **Backend:** Python 3.12, FastAPI, SQLAlchemy (async), Alembic
- **База данных:** PostgreSQL (asyncpg)
- **Шаблоны:** Jinja2
- **Аутентификация:** JWT (access + refresh токены, cookies)
- **Контейнеризация:** Docker, Docker Compose

---

## Быстрый старт

### Локально (без Docker)

```bash
# 1. Клонировать / распаковать проект
cd project

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/macOS

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Скопировать и заполнить переменные окружения
copy .env.example .env        # Windows
# cp .env.example .env        # Linux/macOS

# 5. Применить миграции базы данных
alembic upgrade head

# 6. (Опционально) Заполнить тестовыми данными
python scripts/seed.py

# 7. Запустить сервер
uvicorn app.main:app --reload --port 8000
```

Приложение будет доступно на: http://localhost:8000

### С Docker Compose

```bash
docker-compose up --build
```

## Переменные окружения (.env)

| Переменная | Описание | Пример |
|---|---|---|
| `DATABASE_URL` | URL подключения к PostgreSQL | `postgresql+asyncpg://user:pass@localhost/dbname` |
| `SECRET_KEY` | Секрет для JWT | случайная строка 32+ символов |
| `DEBUG` | Режим отладки | `true` / `false` |
| `DATABASE_POOL_SIZE` | Размер пула соединений | `5` |
| `DATABASE_MAX_OVERFLOW` | Максимальный оверфлоу пула | `10` |

## Миграции базы данных

```bash
# Применить все миграции
alembic upgrade head

# Откатить последнюю миграцию
alembic downgrade -1

# Создать новую миграцию
alembic revision --autogenerate -m "описание изменения"
```

### Исправление существующей БД

Если таблицы `follows` или `book_subscriptions` уже созданы без колонки `updated_at`, выполните в PostgreSQL:

```sql
ALTER TABLE follows ADD COLUMN IF NOT EXISTS updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() NOT NULL;
ALTER TABLE book_subscriptions ADD COLUMN IF NOT EXISTS updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() NOT NULL;
```

## Роли пользователей

| Роль | Возможности |
|---|---|
| **читатель** | Читать книги, оставлять отзывы, добавлять в закладки, подписываться на авторов и книги |
| **автор** | Всё что читатель + публикация собственных книг и глав |
| **модератор** | Управление книгами и отзывами через панель администратора |
| **администратор** | Полный доступ ко всем функциям платформы |

Роль выбирается при регистрации: **«Только читать»** (читатель) или **«Читать и писать»** (автор).

## Основные функции

- 📚 **Каталог** — поиск, фильтрация по жанру, сортировка, разделы русской и иностранной литературы
- ✍️ **Редактор** — создание и публикация книг с главами, теги, предупреждения о содержании
- ⭐ **Отзывы** — оценки 1–5, текстовые отзывы, флаг «содержит спойлеры» (скрытый текст)
- 🔔 **Подписки** — отслеживание авторов и обновлений книг со статусом «В процессе»
- 🔖 **Закладки** — сохранение книг и отслеживание прогресса чтения
- 🛡️ **Панель администратора** — управление пользователями, книгами, отзывами, жалобами

## Авторизация

Вход выполняется по **имени пользователя** и паролю (не по email).

Требования к паролю при регистрации:
- Минимум 8 символов
- Хотя бы одна заглавная латинская буква (A–Z)
- Хотя бы одна цифра (0–9)

Имя пользователя: только латиница, цифры, `_` и `-`, от 3 до 50 символов.
